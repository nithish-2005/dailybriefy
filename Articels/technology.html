Google built a giant fake internet called Mirror Dimension to safely test its AI agents

Google has built a giant fake internet called the Mirror Dimension to safely train Chrome's AI browsing agents and defend them against hidden cyberattacks without putting real user data at risk.

Published on 15 October 2026

Imagine an entire internet filled with shopping sites, social media feeds, and bank dashboards, except none of it is real. That is exactly what Google has built to safely train the new AI browsing agents coming to Google Chrome. Detailed on Google’s security blog, this alternate-universe web is called the Mirror Dimension. It works as a massive, locked-off playground where Chrome’s Gemini-powered "auto browse" feature can click links, fill out forms, download podcasts, and shop online without ever touching a real website or putting actual user data at risk.

Training an AI agent to handle everyday web errands requires running thousands of tests across hundreds of websites. Doing this on the live internet creates big problems. Real websites change constantly, which makes it hard for engineers to repeat tests accurately. Worse, letting an unrefined AI loose on the open web is risky, because one mistake could mess up a real account or cause actual harm.


Because Chrome has strict built-in security checks, engineers had to use custom, forged web certificates inside the sandbox so the browser would not flash warning signs. Google stresses that hackers could not do this to regular Chrome users on the open internet, as it only works because the company has total control over its private test network. Every test also starts from a clean slate so previous actions never affect the next run. AI agents are building the fake web Building thousands of realistic websites by hand would be impossible, so Google put teams of other AI agents to work. Research agents first plan what a site needs, such as working shopping carts and promo code boxes. Builder agents then write the actual website code, while critic agents use Chrome developer tools to click buttons, take screenshots, and send glitches back for fixes. Together, they have built an entire fake web of online stores, recipe sites, local marketplaces, and banking dashboards. Fighting hidden attacks and what comes next A major goal of this project is protecting users from "prompt injection" attacks, where hackers hide secret, harmful instructions inside webpage text or images to hijack an AI. Early on, Google’s AI spotted these tests by noticing strange web addresses, so engineers began hiding attack triggers inside invisible web headers instead. This automated setup lets one security engineer create over 1,000 attack tests daily, more than 30 times what a human could make manually though Google did not share how often its AI passed or failed.
